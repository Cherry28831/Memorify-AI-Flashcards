# 📚 Memorify - AI Flashcards Generator

**Memorify** is a free-to-use AI-powered flashcard generator that helps students and learners easily convert their notes into flashcards using **GROQ LLM**. Built with **React** and **Node.js**, it enables quick creation, review, editing, and export of flashcards in PDF format — all in a simple, distraction-free interface.

---

## 🚀 Features

- 🔮 **AI-Powered Flashcard Generation** using [Groq LLM](https://groq.com/)
- 📝 **Paste Notes or Text** to instantly generate meaningful question-answer flashcards
- ✏️ **Edit, Delete & Reorder Flashcards** with drag-and-drop
- 🔄 **Review Mode**: Flip cards to study with left/right navigation
- 📥 **Download Flashcards as PDF**
- 💾 **Local Storage**: Sessions saved in browser
- 🎯 **Difficulty Levels**: AI assigns Easy/Medium/Hard to each card
- 🖱️ **Simple UI**: Clean, distraction-free interface
- ⚡ **Lightweight and Fast**

---

## 🧱 Tech Stack

- **Frontend**: React + CSS + Lucide Icons
- **Backend**: Node.js + Express
- **AI Integration**: Groq API (Compound model)
- **PDF Generation**: jsPDF
- **Storage**: Browser LocalStorage
- **No Database Required**
